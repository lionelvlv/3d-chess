# AI Usage Disclosure

To ensure transparency regarding my development process, I use AI-assisted tools (primarily Claude Code) to help structure, document, and debug code. 

### How I use AI in this project:
- **Architectural Scaffolding:** Generating initial directory structures, project templates, and boilerplate.
- **Documentation:** Creating and maintaining technical specifications, decision logs, and README documentation based on my project notes.
- **Debugging:** Analyzing log files, identifying edge-case logic errors, and suggesting idiomatic fixes.
- **Testing:** Generating foundational unit and integration test suites.

**My development process:**
I maintain full control over the codebase. All AI-generated code is reviewed, tested, and integrated by me. I adhere to a "lazy" senior developer philosophy: I prefer standard library implementations over external dependencies, clean architecture over complex abstractions, and I prioritize deletion over addition. Every line of code is verified for correctness before being merged.
